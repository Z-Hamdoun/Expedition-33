## Création d'un jeu inspiré du jeu du dinosaure de google.


## Description
Jeu où l'on incarne un personnage qui peut sauter et s'accroupir pour éviter des obstacles.


## Visuals
Depending on what you are making, it can be a good idea to include screenshots or even a video (you'll frequently see GIFs rather than actual videos). Tools like ttygif can help, but check out Asciinema for a more sophisticated method.

## Installation
Utilisation de la bibliothèque pygame pour réaliser le jeu
